# Архитектура

```text
catalog_parser/
  config.py    JSON → ParserConfig и FieldSpec
  extract.py   BeautifulSoup, карточки, поля, URL, дедупликация
  export.py    CSV и XLSX
  cli.py       argparse, локальные файлы и URL
tests/
  test_parser.py
scripts/
  build_demo.py
```

## Поток

```text
config.json ──> ParserConfig
                    │
HTML / URL ──> parse_page ──> Product[]
                    │
             parse_pages ──> dedupe + stats
                    │
             write_csv / write_xlsx
```

## Решения

### Конфиг вместо кода под каждый сайт

Селекторы и обязательность полей вынесены в JSON. Для нового сайта меняется конфиг, а не модуль парсинга.

### Явные страницы

CLI принимает список `--html` или `--url`. Это не даёт скрипту бесконтрольно ходить по всему сайту и упрощает проверку объёма.

### Пропуск, а не мусор

Карточка без обязательного поля не попадает в выгрузку; счётчик `skipped` показывает, что данные неполные.

### Дедупликация по URL

Один товар может встретиться на нескольких страницах. Дубликаты считаются и не попадают в итоговый CSV.

## Границы

- Нет JS-рендера.
- Нет обхода CAPTCHA и авторизации.
- Нет автоматического обнаружения пагинации.
- Нет хранения истории и расписания.
- Нет Google Sheets; экспорт туда — отдельный слой.
